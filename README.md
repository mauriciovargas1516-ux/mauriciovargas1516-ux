### Detalle Arquitectónico de las Plataformas en Vivo

- **Super Hub y Central de Mando GitHub (`github-context-extractor`):** Extractor multi-repositorio en RAM con reparto equitativo por peso en bytes (algoritmo *bin-packing* parametrizable vía URL `parts`/`part`), firmas AST, CMS remoto por lotes vía GitHub REST API (`About`, `requirements.txt`, `README.md`, despliegue masivo) y lectura HTTP Byte-Range sobre Google Drive API con visor PDF.js.
- **Suite de Evaluación de Proyectos (`PROYECTOS-2026`):** Formulación y evaluación privada, social y ambiental bajo normativa SNI / MIDESO 2026 (precios sociales, microeconomía de Fontaine, Matriz de Leopold, Marco Lógico), estudio interactivo a 60 FPS con conectores pedagógicos vivos y compilación en 1 clic de Word, PDF y libros Excel dinámicos en `.zip`.
- **Simulador de Finanzas Avanzadas (`FINANZAS-AVANZADAS-2026`):** Evaluación de activos reales, estructura de capital (CAPM/WACC), FCL, FCI, amortización francesa, sensibilidad multiescenario y simulación de Monte Carlo (50.000 iteraciones) con exportación a Excel de 6 hojas con fórmulas vivas.
- **Motor de Análisis Territorial (`DESARROLLO-Y-GESTION-TERRITORIAL-2026`):** Plataforma interactiva de 9 módulos con técnicas de análisis regional SII (ILPES, Shift & Share MADE, Silva Lira CEPAL), convergencia econométrica REAT, movilidad de Quah, constructor de redes empresariales en vivo (Dini 2010 / UCINET / ELITE), ordenamiento territorial (97 comunas) y laboratorio de simulación teórica (Krugman, Perroux, Granovetter, Christaller).
- **Suite de Gestión Tributaria (`GESTION-TRIBUTARIA-2026`):** Normativa del Código Tributario, simulador de Rentas (1ª y 2ª Categoría LIR), liquidación de IVA / proporcionalidad y remanente UTM F29 (DL 825 / Ley 21.420) y analítica del Plan de Gestión de Cumplimiento Tributario (PGCT 2026 SII).
- **Sincronizador ULagos Virtual (`moodle-hybrid-scraper`):** Pipeline CI/CD serverless en GitHub Actions (cron programado 2 veces al día) con autenticación headless (`Selenium`), transferencia de cookies a sesiones HTTP (`Requests` / `BeautifulSoup4`), filtrado en streaming de binarios multimedia pesados y distribución multi-repositorio incremental con deduplicación por hash Git SHA-1 vía GitHub REST API y gestión cifrada de secretos.
